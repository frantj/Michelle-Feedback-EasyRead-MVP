Easy Read Skill for Claude

Make Easy Read documents inside Claude. Give Claude some text, a PDF or a Word file. You get back a Word document with short sentences and a picture beside every sentence.

Download the skill (free) How to install it

A .zip file of about 5 MB. Always the latest version — see what changed.

What the skill does

The skill uses the same Easy Read rules and picture library as this website. When you ask Claude to make something Easy Read, it:

  1. Reads your text, PDF or Word file
  2. Rewrites it in short sentences, with one idea in each sentence
  3. Picks a picture for every sentence from over 370 pictures
  4. Checks the result against the Easy Read rules and fixes any problems
  5. Gives you a Word document to download, edit and print

What you need

  • A Claude account at claude.ai. Skills work on the free plan and on paid plans.
  • Code execution turned on. In Claude, go to Settings → Capabilities and turn it on. Claude needs it to build the Word document.
  • On a Claude Team or Enterprise plan, an owner of your organisation may need to allow skills and code execution first.

How to install it

  1. Download the skill. Do not unzip it.
  2. In Claude, go to Customize → Skills.
  3. Select +, then Create skill, then Upload a skill.
  4. Choose the easy-read.zip file you downloaded.
  5. Check that the skill is turned on in your list of skills.

To update to a new version, download the skill again and upload it in place of the old one.

Try it

Start a new chat in Claude and try one of these:

  • "Make this Easy Read:" and then paste your text
  • "Turn this leaflet into an Easy Read version", with a PDF or Word file attached
  • "Make an Easy Read summary of this letter for my client", with the letter attached

Your privacy

When you use the skill, your text stays in your own Claude account. It is not sent to this website or to OpenAI. Anthropic, the company that makes Claude, handles it under your Claude account's terms and privacy settings.
